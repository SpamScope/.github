# 🔎 SpamScope

**Understand email. Expose the threats.**

We build tools to help analysts understand email and investigate threats while preserving the structure and evidence in each message.

SpamScope started as an email-analysis platform. Its parsing engine became **mail-parser**, an independent Python library for examining messages beyond their visible content.

## 🧩 Projects

### 📨 [mail-parser](https://github.com/SpamScope/mail-parser)

Parse email into structured data for analysis and automation. Inspect headers, message bodies, attachments, metadata, and Received hops, with access to raw values and address and MIME defects.

Use the results in Python or export them as JSON to support your investigation workflows.

[Explore the repository](https://github.com/SpamScope/mail-parser) · [Install from PyPI](https://pypi.org/project/mail-parser/)
