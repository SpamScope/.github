# SpamScope

Terms used to describe the SpamScope projects in the organization profile.

## Language

**SpamScope**:
The email-analysis project from which the mail-parser library originated, and the organization that presents these related tools.
_Avoid_: Using SpamScope as another name for mail-parser.

**mail-parser**:
The independent Python library extracted from SpamScope for examining email structure, content, metadata, and parsing defects.
_Avoid_: Mail Parser, MailParser.

**MailXray**:
The forthcoming self-hosted email threat-analysis platform combining mail-parser and AI.
_Avoid_: Describing MailXray as an already available service.
